▍Step-by-step guide

Installing Domain OS from scratch

From downloading the official Windows 11 Pro image to the first game. Follow the steps in order and skip nothing: almost every problem after an install is a skipped step, a modified Windows image or third-party "optimizers".

Time: about an hour, the playbook itself takes about 10 minutes/You need a USB stick of 8 GB or more/Windows 11 Pro · 25H2 / 26H2

01▍Before you start

What to prepare

Do all of this on any PC with internet, before reinstalling.

  1. Back up your important files to another drive or the cloud. A clean install wipes the system drive completely.
  2. Make sure you have Windows 11 Pro or a Pro key. Domain OS installs on Pro only: on Home the install stops at the first step and changes nothing. To check: Settings → System → About ("Edition").
  3. Prepare a folder for the USB stick (put it on the stick next to the Windows installer, see step 2):
    • No-WU-Drivers.reg — stops Windows from installing its own drivers;
    • AME Wizard — the program that installs the playbook;
    • Domain-OS-2.3.1.apbx — the playbook itself;
    • the network card driver from the maker of your motherboard or laptop — in case Windows has no internet after the install.
▍Original image only

Do not use "lite", "gaming" or any modified Windows images or other people’s builds. The playbook expects plain Windows from Microsoft: modified images already have components removed or broken, and the result is unpredictable.

02▍USB stick

Official image and a bootable USB stick

Windows 11 comes from the Microsoft website only.

  1. Download the image from Microsoft’s Windows 11 download page: "Download Windows 11 Disk Image (ISO)", edition "Windows 11 (multi-edition ISO)", your language. One image holds both Home and Pro.
  2. Write the image to the USB stick with Rufus (or Microsoft’s Media Creation Tool). In Rufus, after "Start" a Windows options window appears:
    • you may tick "Remove requirement for an online Microsoft account" and "Create a local account" — then Setup does not ask for internet or a Microsoft account;
    • do not tick "Remove requirement for 4GB+ RAM, Secure Boot and TPM 2.0": Windows 11 and anti-cheats need TPM and Secure Boot.
  3. Copy the folder from step 1 onto the stick (No-WU-Drivers.reg, AME Wizard, the playbook, the network driver).
03▍Windows

A clean install of Windows 11 Pro

The most important part: everything else depends on it.

  1. Disconnect the internet: unplug the network cable, do not join Wi-Fi. You need the internet only after step 4.
  2. Boot from the USB stick: while the PC starts, press the boot menu key (usually F8, F11, F12 or Esc, depending on the board) and pick the stick. Nothing needs to be turned off in the BIOS: leave Secure Boot and TPM on.
  3. Choose Windows 11 Pro. At the product key step press "I don’t have a product key" — you can activate later. If Setup does not ask for the edition and installs Home, a Home key is stored in your firmware: after the install switch to Pro with your key in Settings → System → Activation → Change product key.
  4. Delete all partitions on the drive you install Windows to and pick the resulting "Unallocated space". Leave other drives alone. This way no old drivers, programs or tweaks stay behind.
  5. Go through the first setup. If the stick was made in Rufus with a local account, Windows does not ask for the internet. You may switch everything off in the privacy questions — the playbook turns telemetry off anyway.
04▍Updates

First start and updates

The order matters here: first the driver block, then the internet.

  1. Run No-WU-Drivers.reg from the stick (double-click → "Yes") while the internet is still disconnected. Otherwise Windows Update installs its own, often old, drivers first.
  2. Connect the internet. If there is no connection, install the network driver from the stick, and only that one.
  3. Install all updates: Settings → Windows Update → Check for updates. Restart and repeat until it says "You’re up to date".
  4. Check the version: Win+R → winver. It must say Windows 11 Pro, version 25H2 (build 26200) or 26H2 (build 26300). On 24H2, update through Windows Update first.
▍Install nothing before the playbook

Before the playbook, do not install graphics drivers, games, launchers, antivirus or "optimizers". The only exception is the network driver if there is no internet without it. Drivers come afterwards, with the Domain OS driver guide.

05▍Playbook

Installing Domain OS

About 10 minutes. Leave the PC alone meanwhile.

  1. Laptop: plug in the charger. AME Wizard does not start on battery. The internet must be connected.
  2. Open AME Wizard and drag Domain-OS-2.3.1.apbx into its window. If Windows asks whether to run it, allow it.
  3. Tick the boxes you want. If unsure, leave them as they are: the defaults suit most people. What every box does is in the table on the main page.
  4. Start the install and wait. Do not turn the PC off, do not close the window, do not start other programs. At the end the PC restarts by itself.
▍If something goes wrong

The install log is in %ProgramData%\Domain OS\Logs\install.log. Everything can be undone: Start → Domain OS → Undo Domain OS, then restart.

06▍Drivers

Drivers after the install

After the restart a page with drivers for exactly your PC opens.

  1. Graphics driver — from the official NVIDIA, AMD or Intel site (links on the page). For NVIDIA you can use NVCleanstall to install only the driver itself.
  2. Chipset driver — from the AMD or Intel site, via the link on the page.
  3. Everything else (audio, network, Wi-Fi, Bluetooth) — from the maker of your motherboard or laptop, only if something does not work.
  4. Restart.
▍No driver packs

Do not use driver pack programs or "auto updaters". They install whatever they find, often old or wrong versions. Official sites only.

07▍Toolbox

Setting up Toolbox

Toolbox 1.16.1 is already installed, the shortcut is on the desktop. You do this once.

  1. Open Toolbox and press "Turn on Auto". From then on it finds the game every time by itself.
  2. With the game closed, press "Optimize devices" once and restart the PC. If Windows does not start after that, everything is reverted by itself.
  3. Optional: "Auto-tune" during a game (about 8 minutes), then "Apply". More on the Toolbox page.
08▍Check

Check that everything is in place

Two minutes, and you know the install went right.

01

winver: Windows 11 Pro, 25H2 or 26H2.

02

Settings → Gaming → Game Mode: on.

03

Windows Security: virus protection is on — Domain OS does not touch it.

04

Start → the Domain OS folder: Undo Domain OS and Domain OS Toolbox are there. The Toolbox icon is in the tray.

05

Windows Update works: security updates keep coming.

06

In Toolbox the "This system" panel shows your Windows, the graphics card with its driver and "Game Mode: on".

09▍Common mistakes

What makes the build work badly

Each of these has happened to users. Check yourself.

01

A modified or "lite" Windows image instead of the original from Microsoft.

02

Installing over an old, long-used system with old drivers and programs. Install on a clean Windows.

03

Third-party tweaks, "optimizers" and cleaners before or after Domain OS. They change the system with no description and no undo; after them nobody can help.

04

The internet was connected before No-WU-Drivers.reg — Windows installed its own drivers. Fix: install the right drivers from the official sites over them.

05

Updates not fully installed before the playbook.

06

TPM or Secure Boot turned off — anti-cheats (FACEIT, Vanguard and others) may refuse to start.

07

An interrupted install: the PC was turned off, AME Wizard closed, the laptop battery died. Run the playbook again — it installs over itself.

08

Driver packs instead of the official sites.
