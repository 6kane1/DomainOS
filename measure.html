How to measure yourself

Two ways: a button in Toolbox and the DomainSchedTest tool. One rule everywhere: the same number of runs per variant.

Rules for a fair comparison

  • The same PC, the same drivers and game settings. Change one thing — the one you compare.
  • The same number of runs for each variant (for example 3 and 3). Compare the means and the ranges: when the ranges overlap, the difference is noise.
  • The same scene: for example a deathmatch with bots on one map. Live play is noisy, so look at the ranges, not at one number.
  • Idle: 10–15 minutes after boot, everything closed, do not touch the PC.

Easiest: the Check page in Toolbox

  1. Start the game from Toolbox's watchlist.
  2. Toolbox → Check → "One run (30 s)".
  3. Switch to the game within 10 seconds and play the same scene until the second beep. To compare two variants, make the same number of runs of each.
  4. The report DomainOS-Check-….txt appears on the desktop: FPS, 1% and 0.1% low, the longest frame, hitches, the game threads' waits and a hint whether the processor or the graphics card limits the frame rate.

In detail: DomainSchedTest

The benchmark tool DomainSchedTest is in Discord, channel 07・schedtest. PowerShell as administrator in the tool's folder:

.\DomainSchedTest.exe --mode game --seconds 30 --process cs2 --ymax 800 --runs 3 --label "my variant"

--runs 3 makes three runs in a row and writes one table, series.txt, with means and ranges. Idle: --mode idle without --process.

Where to send it

Post results in Discord, channel 18・results: the bot answers with a chart. The summary is on the Results page.
