Versions and changes

Only the current version links its files: always install that one. Older versions are here for the record.

Domain OS 2.3.4 · Toolbox 1.17.2 27.11.2026current

  • A very important hotfix. The Windows changes are the same as in 2.3.3; the playbook carries Toolbox 1.17.2, and Toolbox 1.17.x updates itself to it.
  • Toolbox 1.17.2: CS2 under FACEIT is found and kept again (FACEIT strips the rights of access to cs2, and 1.17.1 took the game for ended).
  • Toolbox 1.17.2: "Ideal cores for all game threads" is off by default: a laptop had flicker and stutters with it.
  • Toolbox 1.17.2: Auto-tune is removed, no real benefit in measurements.

Domain OS 2.3.2 · Toolbox 1.17.0 27.11.2026

Domain OS 2.3.1 · Toolbox 1.16.1 22.11.2026

  • The Windows changes are the same as in 2.3.0; the playbook carries the new Toolbox 1.16.1.
  • Toolbox 1.16.1: wait probe: Dynamic Top-5 picks the game's threads by load and by how long they wait for a core, and moves a thread only for a clear reason.
  • Toolbox 1.16.1: CPUs with one cache and no E-cores (7800X3D, 9800X3D, 7700X) give the game every core; a Core mask button with a short guide.
  • Toolbox 1.16.1: graphics-driver and interrupt cores are held 60 s, the game's threads are no longer moved every few seconds; a Black box explains every stutter in plain words.

Domain OS 2.3.0 · Toolbox 1.16.0 21.11.2026

  • Tips, Cortana, Maps and Mobile devices are kept; the Store stays even with Maximum. Before the install AME asks to switch off the Windows Security toggles: switch them back on after the restart.
  • More ads and suggestions off, diagnostic data level 0, Firewall on without notifications, no Insider builds; HAGS always on; without the tick UAC asks for the password or PIN.
  • Toolbox 1.16.0: page Updates and testing, Dynamic Top-5 only, Apply the layout with a confirmation, burst guard; on 6 cores or fewer every core to the game.

Domain OS 2.2.4 · Toolbox 1.15.0 19.11.2026

  • Undo checked with the full cycle on a real PC: install → Check → Undo (Failed: 0) → every setting compared → install again.
  • Undo puts back services and tasks only SYSTEM may change and values only Windows (TrustedInstaller) may change.
  • Undo puts the taskbar pin order back again; the install no longer stops at the wallpapers.
  • The playbook archive is built and attested on GitHub.

Domain OS 2.2.0 · Toolbox 1.15.0 19.11.2026

  • The install stops on any error and checks everything it set at the end.
  • New: Start → Domain OS → Check Domain OS — the state of the PC and whether Undo is ready; it changes nothing.
  • The UAC prompt stays by default; Undo puts back more (SYSTEM services, power plan, pins, wallpapers).
  • Toolbox 1.15.0: signed updates, AMD Radeon overclocking (behind its flag), a notice for a new playbook, data in a protected folder.

Domain OS 2.1.1 · Toolbox 1.14.1 18.11.2026

  • Windows 11 Pro only, 25H2 and 26H2; on other editions the install stops before any change.

Domain OS 2.0.0 · Toolbox 1.11.1 18.11.2026

  • The game stays off the graphics-driver cores: Toolbox finds them from the 3rd second of play.
  • Auto no longer switches off when you close the game.
  • Removed what did not help in measurements: core parking, hard thread pinning, the frame-time watchdog and more.
  • Russian and English only, a complete translation.
