Frequently asked questions

Answers to the questions people ask most. The bot gives the same answers in Discord. Your question is not here? Ask in Discord, channel 14・help.

What Domain OS is

A playbook (installer) that cleans up a fresh Windows 11 Pro for games in ~10 min: removes ads, bloat and telemetry, sets up power and Game Mode. Windows protection stays, everything can be undone. Plus Toolbox — an app that helps the game while you play. https://6kane1.github.io/DomainOS/

Where to download

Everything is in Discord #04・downloads and on the website: No-WU-Drivers.reg, AME Wizard, Domain-OS.apbx. Toolbox comes with the build.

How to install

Step-by-step guide from a clean Windows: https://6kane1.github.io/DomainOS/install.html — short version in Discord #05・guide. AME Wizard needs the internet and, on a laptop, the charger plugged in.

Which Windows

Windows 11 Pro, version 25H2 or 26H2 (Win+R → winver). Windows 10 and 24H2 are not supported.

Is it safe? Can I get banned?

Windows protection stays as it is: Defender, memory integrity, Secure Boot and TPM are not changed. Domain OS does not touch game files and injects nothing into games: it changes only Windows settings, and every change can be undone. Anti-cheat developers have not officially confirmed compatibility, so the decision is yours.

How to use Toolbox

Open Toolbox → Turn on Auto → start the game. Once, with the game closed: Optimize devices → restart. Details in Discord #06・toolbox.

Toolbox does not pick up the game

Auto must be on and the game in front (not minimised). Some games are protected by their anti-cheat — then Toolbox leaves the game alone but still quiets background programs.

Laptops

Laptop support is not confirmed yet — at your own risk. Keep the charger plugged in during the install.

Updates

Security updates keep coming; big feature updates are held on 26H2 (option). A new Domain OS version installs right over the old one in AME Wizard.

Wallpapers

Change them as usual: Settings → Personalization. Lock screen slideshow: Personalization → Lock screen → Slideshow → C:\Windows\Web\Wallpaper\Domain OS.

Benchmarks

The benchmark tool and a beginner guide are in Discord #07・schedtest; post results in Discord #18・results — the bot answers with a chart.

The install stops at the first step

Domain OS installs on Windows 11 Pro only. Check Settings → System → About. On Home: switch to Pro with a Pro key (Settings → System → Activation).

How to undo

Start → Domain OS → Undo Domain OS, then restart. Toolbox changes: "Undo everything" in Toolbox.

Drivers

Graphics and chipset drivers only from the official NVIDIA / AMD / Intel sites, no driver packs. The driver page opens after the first restart.

FPS / stutter

Toolbox: Auto on, then once "Optimize devices" with the game closed and restart. Steam: Settings → Interface → GPU acceleration in web views off. If the GPU is at 95–100%, average FPS will barely move — that is the card, not Windows.

Anti-cheat

Domain OS keeps Defender, VBS/Memory Integrity, Secure Boot and TPM as Windows has them. If an anti-cheat refuses: check that TPM and Secure Boot are on in the BIOS and close third-party tools that load drivers.

Crashes, blue screen, does not start

If Windows did not start after "Optimize devices" in Toolbox, the changes are undone by themselves at the next start. Otherwise: Start → Domain OS → Undo Domain OS (in Safe Mode: DomainScheduler.exe --revert-devices). Please attach %ProgramData%\Domain OS\Logs\install.log and the blue-screen code if there was one.
