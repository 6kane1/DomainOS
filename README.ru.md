# Domain OS

[English](README.md) | **Русский**

Плейбук для [AME Wizard](https://ameliorated.io), который готовит **Windows 11 24H2 и 25H2 (сборки 26100, 26200), Home и Pro**, к играм.

> **Лучше всего на 25H2:** сейчас плейбук стабильнее всего работает на Windows 11 25H2. Поддержка 26H2 появится в ближайшем обновлении после 2.0.0.

**Короткий список изменений, каждое объяснено и проверяемо.** У каждого пункта ниже указан ключ реестра, служба или параметр, который он меняет.

> **Перед началом**
> - **Его можно отменить без переустановки Windows** (см. [Откат](#откат)). Удалённые приложения ставятся заново из Store. Всё равно сначала попробуйте в виртуальной машине.
> - **Средний FPS от плейбука не растёт.** Вы получаете меньше фоновых процессов, отсутствие рекламы и принудительных перезагрузок и систему, настроенную одинаково каждый раз.
> - Версия 2.0.0 новая и мало проверена. Сообщайте о том, что ломается.

## Что остаётся нетронутым — намеренно

| Компонент | Почему остаётся |
|---|---|
| Microsoft Defender, SmartScreen, «Безопасность Windows» | Без них ПК не защищён, а античиты перестают работать. |
| Secure Boot, TPM, VBS, целостность памяти, защитные механизмы ядра | Их проверяют FACEIT, Vanguard, EasyAntiCheat и BattlEye. |
| Обновления безопасности и качества, базы Defender | Система без них становится небезопасной за несколько недель. |
| Xbox Identity Provider, Gaming Services, приложение Game Bar | Через них игры входят в учётную запись и сохраняются. Оверлей Game Bar выключен, но приложение не удаляется. |
| Microsoft Store, App Installer (winget), Edge, WebView2 | Нужны лаунчерам и многим программам. Store можно убрать опцией «Maximum». |
| Основные службы Windows | Отключаются только службы, бесполезные на игровом ПК, каждая названа и объяснена. Массовое отключение вслепую ломает функции. |

## Поддерживаемые версии Windows

| Версия | Сборка | Обновления безопасности от Microsoft (Home и Pro) |
|---|---|---|
| 25H2 | 26200 | до октября 2027 — **рекомендуется** |
| 24H2 | 26100 | закончились в октябре 2026 |

Даты взяты со [страницы жизненного цикла Microsoft](https://learn.microsoft.com/lifecycle/products/windows-11-home-and-pro). Плейбук не отключает обновления безопасности ни на одной версии, но для 24H2 Microsoft их просто больше не выпускает. С галочкой «Оставаться на установленной версии» такой ПК остаётся без исправлений безопасности; снимите её там, если хотите, чтобы Windows перешла на поддерживаемый выпуск.

Плейбук запускался только на 25H2. На 24H2 применяется тот же список; пункты, которых там нет, пропускаются.

## Что меняет Domain OS

Каждый пункт находится в `playbook/Configuration/Tasks/*.yml` с комментарием рядом.

### Встроенные приложения (опция, включена)
Удаляются приложения с рекламой или фоновым запуском: Clipchamp, Новости, Погода, поиск Bing, Solitaire, Teams, приложение Copilot, новый Outlook, Dev Home, Feedback Hub, «Техническая поддержка», «Советы», хаб Microsoft 365, Power Automate, To Do, «Кино и ТВ», Cortana, Карты, старая Почта, Family, «Связь с телефоном», «Мобильные устройства» (Cross Device), Виджеты и рекламные заглушки (Spotify, Disney+, LinkedIn). Windows запрещено возвращать Dev Home и Outlook и молча ставить «рекомендуемые» приложения.

- **OneDrive** (опция, включена): удаляется собственным деинсталлятором. Файлы остаются.
- **Maximum** (опция, выключена): дополнительно Store, приложение Xbox, Фотографии, Камера, Запись голоса, Часы, Записки.

### Приватность и реклама
- Диагностические данные на обязательном уровне; служба телеметрии и её помощник отключены.
- Отключён плановый сбор данных, включая оценку совместимости, известную долгими всплесками нагрузки на диск и процессор, и её второе задание `MareBackup`.
- Сеансы трассировки телеметрии (`Diagtrack-Listener`, `SQMLogger`) больше не запускаются при загрузке: после отключения службы их события никто не читал.
- Включены политики «Отключить телеметрию приложений» и «Отключить сборщик инвентаризации». Механизм совместимости старых игр не тронут.
- Все остальные документированные политики диагностических данных, которые работают на Home и Pro: без запросов отзывов, без имени устройства в данных, без сбора дополнительных журналов и дампов, без загрузки OneSettings, без уведомления о смене уровня; CEIP, средство записи действий, отчёты об ошибках Windows и отчёты MRT о заражениях выключены; без обучения на наборе текста и рукописном вводе, без онлайн-распознавания речи, без передачи рукописных данных; необязательные диагностические данные Edge выключены (Edge, как при любой политике, покажет «управляется вашей организацией»).
- Выключены рекламный идентификатор, персонализированные предложения, запросы отзывов, журнал действий и Recall.
- Выключены предложения и реклама в «Пуске», «Параметрах», на экране блокировки и в уведомлениях.
- Поиск в «Пуске» больше не отправляет набранное в Bing. Панель виджетов выключена.

### Службы и фоновая работа
- **Базовый набор (опция, включена):** восемь заданий по расписанию от удалённых приложений и сбора данных (карты, семейная безопасность, прокси проверки диска, SQM). Edge остаётся, но больше не держит процессы после закрытия окна. Сами службы остаются такими, как их настраивает Windows: печать, Bluetooth, карты, факс, диагностика, синхронизация и мелкие системные драйверы не трогаются.
- **На ваш выбор (опции, выключены):** индексирование файлов, гибернация с быстрым запуском, фоновая работа приложений из Store. Каждая из них отнимает функцию, поэтому каждая — отдельной галочкой.
- **Службы и задачи телеметрии (применяется всегда):** отчёты об ошибках (WerSvc), помощник совместимости (PcaSvc), телеметрия (DiagTrack), хост AI-компонентов Windows (WSAIFabricSvc), сборщик сведений о совместимости (InventorySvc); служба отслеживания изменившихся связей (TrkWks) удаляется из Windows после резервной копии её настроек, откат регистрирует её снова; а также 14 заданий телеметрии: перепись устройств, отправка данных об использовании, телеметрия энергопотребления, проверка автозагрузки, сканирование неполадок, диагностика диска и питания, WinSAT, отправка отчётов об ошибках. Дефрагментация/TRIM, резервная копия реестра, точки восстановления, SysMain, синхронизация времени и Defender остаются. Версии 1.5.0–1.6.0 выключали больше (диагностику, синхронизацию, мелкие драйверы, печать, Bluetooth, базовые службы, политику перезагрузки); установка 1.6.0 возвращает всё это к значениям, которые были до первой установки.
- **Тип запуска гипервизора:** версии 1.5.7–1.6.0 выключали запуск гипервизора, если виртуализация в BIOS была выключена. Этого шага больше нет (если потом включить виртуализацию, целостность памяти и VBS молча не запустились бы); установка 1.6.2 или новее возвращает прежнее значение.
- Что это даёт: меньше процессов и занятой памяти после загрузки — это видно в диспетчере задач. Само по себе FPS это не повышает.
- Никогда не отключаются: Defender, Центр обновления, звук, сеть, ввод, планировщик, WMI, службы Xbox, службы TPM и Secure Boot, службы античитов.

### Центр обновления Windows (две опции, включены)
- **Оставаться на установленной версии** (24H2 или 25H2): без обновлений компонентов. См. примечание о поддерживаемых версиях ниже.
- **Без драйверов из Центра обновления:** драйверы производителей вы ставите сами; инструкция покажет какие.

Обновления безопасности продолжают приходить. На Windows Home часть этих политик система может проигнорировать. В папке «Domain OS» в меню «Пуск» есть ярлык, который возвращает всё как было.

### Игровые настройки
- **Запись игр выключена полностью:** фоновая запись (Game DVR), запись вручную, звук, курсор и микрофон в записи, плюс политика, запрещающая запись и трансляции. Фоновая запись отнимает время видеокарты и диска в каждой игре.
- **Ускорение указателя выключено.**
- **Сочетания залипания, фильтрации и озвучивания клавиш выключены** — пять нажатий Shift больше не выбрасывают окно поверх игры.
- **Game Bar выключен (с 1.6.8).** Не открывается по Win+G и кнопке Xbox на геймпаде, но само приложение остаётся: его можно включить в Параметры → Игры. Откат возвращает прежние значения.
- **Xbox mode выключен (с 1.6.8):** полноэкранный режим Xbox (Параметры → Игры → Xbox mode) не используется как домашний экран. Само приложение Xbox остаётся. Откат возвращает прежнее значение.
- **Игровой режим остаётся включённым**, как в Windows по умолчанию: драйвер AMD 3D V-Cache на Ryzen X3D с двумя CCD по нему держит игры на CCD с кэшем, а ещё он не даёт Центру обновления ставить драйверы и просить перезагрузку во время игры.
- **Аппаратное ускорение планирования GPU (HAGS), включено по умолчанию (опция):** `HwSchMode` = 2 в `HKLM\SYSTEM\CurrentControlSet\Control\GraphicsDrivers`. Видеокарта сама распределяет свою работу, это снимает часть работы с процессора и задержку при отправке кадров. Нужны поддерживаемые видеокарта и драйвер (NVIDIA GTX 10 и новее, AMD RX 5000 и новее, Intel Arc), иначе Windows значение игнорирует. Работает после перезагрузки; откат возвращает прежнее значение.
- **`Win32PrioritySeparation` = 0x18:** длинные фиксированные кванты времени, одинаковые для активной программы и фоновых (стандартное значение Windows 2 даёт короткие переменные кванты, у активной программы в 3 раза длиннее). Версии 1.4.0–1.6.6 ставили 0x25. Сравните с 2 в Domain FrameTime; откат возвращает прежнее значение.

### Интерфейс
Показываются расширения файлов, проводник открывается на «Этот компьютер». Влияния на производительность не заявляется.

- **Чистая панель задач** (опция, включена): все закреплённые программы откреплены, кнопки поиска, представления задач и чата скрыты — остаётся только кнопка «Пуск» (и программы, пока они запущены). Исходные закрепления сохраняются, откат их возвращает. Панель очищается только при первой установке: если новая версия ставится поверх старой, закреплённые с тех пор программы остаются. Без этой опции поиск становится значком.
- **Закрепления в «Пуске»** (вместе с удалением встроенных приложений): список закреплённых собирается заново из установленных программ — Параметры, Проводник, Edge, Domain OS Toolbox, а также Store, Xbox, Терминал и Блокнот, если они есть, — поэтому плитки удалённых приложений (Copilot, Teams, Outlook, Solitaire, папка «Другое») исчезают. Используется политика `ConfigureStartPins` с `applyOnce` (Windows 11 24H2 с KB5062660 и новее): «Пуск» заменяет список закреплённых при следующем входе и больше никогда, поэтому закрепления можно менять как обычно. На старых сборках одноразовая задача снимает политику после того, как она сработала. Только при первой установке; откат возвращает исходные закрепления.

- **Тёмная тема** (опция, включена): для Windows и приложений.
- **Уведомления выключены** (опция, включена): главный переключатель в «Параметры → Система → Уведомления». Никаких всплывающих окон и звуков поверх игры. Defender продолжает работать, его состояние видно в «Безопасности Windows». Уведомления можно включить в «Параметрах» в любой момент.
- **Права администратора без запроса UAC** (опция, включена): ваша учётная запись и так была администратором; теперь программа, которой нужны права администратора, получает их без окна «Разрешить этому приложению вносить изменения?». Сам UAC остаётся включённым, поэтому приложения Store, Xbox и античиты работают. Цена: любая запущенная программа, которая просит права, получает их молча, поэтому запускайте только то, чему доверяете. Снимите галочку, чтобы окно осталось; откат возвращает его.

### План питания (опция, включена)
**Domain OS** — свежая копия плана Windows «Сбалансированный», в которой изменены четыре параметра при питании от сети и больше ничего. Параметры процессора, парковка ядер и буст остаются как в «Сбалансированном» — под него AMD и Intel настраивают свои процессоры; от батареи ноутбук работает как со «Сбалансированным».

| Параметр | Значение | Что делает |
|---|---|---|
| Выборочная приостановка USB | выкл. | USB-хабы, мышь, клавиатура, гарнитура и USB-звук не засыпают. |
| Управление питанием канала PCI Express (ASPM) | выкл. | Видеокарта, NVMe и сетевая карта не уводят линию PCIe в энергосбережение. |
| Отключать дисплей через | никогда | |
| Отключать диск через | никогда | |

Прежний активный план запоминается; откат снова делает его активным и удаляет этот. Установка 1.6.0 поверх старой версии собирает план заново из «Сбалансированного», так что параметры процессора прежнего плана «Domain OS Low Latency» уходят.

### Инструменты
- **DomainScheduler** (опция, включена): ставится в `Program Files\Domain OS` и запускается с Windows для каждого пользователя. Расставляет потоки игры и понижает фоновые программы, пока вы играете.
- **Библиотеки** (опция, включена): Visual C++ 2015–2022 x64 и x86, DirectX June 2010, 7-Zip — скачиваются у производителей; файлы Microsoft принимаются только с действительной подписью Microsoft.
- **Инструкция по драйверам** (опция, включена): после перезагрузки открывается страница, составленная для вашего ПК: какие драйверы ставить, в каком порядке, со ссылками на официальные страницы, и как поставить драйвер NVIDIA без лишнего через NVCleanstall. Она же проверяет частоту обновления монитора и работает ли память на заявленной частоте.
- **Обои** (опция, включена): картинка Domain OS копируется в `Windows\Web\Wallpaper\Domain OS` и выбирается. Это обычная настройка: другую картинку можно выбрать в «Параметрах» в любой момент.
- **Ярлык:** «Domain OS Toolbox» на рабочем столе и в меню «Пуск».

## Откат

Domain OS меняет настройки, а не вырезает компоненты Windows. Поэтому его можно вернуть.

- **Перед первым изменением** плейбук записывает текущее состояние каждого значения реестра, службы и задания, которые может затронуть (`%ProgramData%\Domain OS\Undo\state.json`).
- **Пуск → Domain OS → Undo Domain OS** возвращает именно это состояние: реестр, типы запуска служб, задания планировщика, гибернацию, OneDrive. После этого перезагрузитесь.
- **Удалённые приложения** автоматически не возвращаются: скрипт перечисляет их, переустанавливает Microsoft Store, если он был удалён, а нужные вы ставите из Store сами.
- Запуск с `-WhatIf` показывает, что будет сделано, а с `-RemoveTools` заодно убирает программу Domain OS.
- Настройки пользователя восстанавливаются для той учётной записи, от которой запущен скрипт.

### Попробовать версию, вернуться, поставить новую
1. Примените версию. Её номер и дата записываются в `%ProgramData%\Domain OS\history.log`.
2. Если не понравилось: **Undo Domain OS**, перезагрузка. Windows такая же, как до плейбука; сохранённое состояние израсходовано.
3. Примените новую версию как в первый раз: перед первым изменением она сохранит свежее состояние.

Новую версию можно применить и **поверх** старой без отката: исходное состояние сохраняется, а то, что новая версия затрагивает дополнительно, добавляется к нему — один откат по-прежнему вернёт всё.

## Рассмотрено и не включено

| Изменение | Почему его нет |
|---|---|
| Разрешение таймера, параметры тиков `bcdedit` | С Windows 10 2004 запрос таймера действует на процесс; воспроизводимого выигрыша нет. |
| MMCSS / `SystemResponsiveness` / `NetworkThrottlingIndex` | Влияют только на потоки мультимедийного класса; воспроизводимого выигрыша в играх нет. |
| Отключение поиска | Ломает поиск файлов; сэкономленная память не видна во времени кадра. (SysMain всегда остаётся включённым.) |
| Отключение состояний простоя процессора (`IDLEDISABLE`), пороги и интервалы производительности | Отключение простоя повышает температуру и отнимает запас для буста; пороги игнорируются процессорами с аппаратным управлением частотой (Intel HWP, AMD CPPC). |
| Отключение ~40 сеансов ETW и ~120 плановых заданий | Задания работают в окне обслуживания, когда ПК простаивает; в игре они не выполняются. Отключены только сеансы службы, которую мы сами выключили. |
| Отключение `Ndu`, `DPS` | Механизм есть (`Ndu` стоит на сетевом пути), но замеров нет. Появится, когда будет трасса WPA с цифрами. |
| `SvcHostSplitThresholdInKB` | Экономит 100–200 МБ памяти, процессор не разгружает, службы теряют изоляцию друг от друга. |
| Десятки недокументированных значений в `Control\Power` и `Session Manager\kernel` | Нет подтверждения, что актуальные сборки их вообще читают. |
| Отключение полноэкранных оптимизаций | Нет воспроизводимого выигрыша; оптимизации нужны для режима flip и VRR. |
| Отключение защитных механизмов, VBS, Defender | На части систем измеримо, но ценой безопасности и поддержки античитов. Не предлагается. |

## Как пользоваться
1. Установите чистую Windows 11 (Home или Pro) — рекомендуется 25H2, подходит также 24H2. **До первого подключения к интернету** запустите `extras/No-WU-Drivers.reg`: иначе Центр обновления поставит свои драйверы раньше, чем плейбук успеет это запретить. Затем завершите обновления и перезагрузитесь.
2. Скачайте AME Wizard и `Domain-OS-1.2.1.apbx`.
3. Перетащите `.apbx` в AME Wizard, выберите опции, запустите.
4. Перезагрузитесь. Откроется инструкция по драйверам: пройдите её сверху вниз.

AME Wizard сообщит, что плейбук не верифицирован: верификацию выдаёт команда AME, у проекта её пока нет.

## Сборка из исходников
`./build.sh` (нужны `7zr` и Python 3): проверяет файлы задач и упаковывает `playbook/` в архив 7z с паролем `malte`, как ожидает AME Wizard. Программы Toolbox в репозитории нет: скачайте `DomainOS-Toolbox-1.8.0.exe` с [сайта](https://6kane1.github.io/DomainOS/ru/scheduler.html) и сохраните как `toolbox/DomainScheduler.exe` или передайте путь: `./build.sh путь/к/DomainScheduler.exe`. Без неё плейбук собирается без программы.
