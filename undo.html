How to undo Domain OS

Undo puts Windows back to how it was before your very first Domain OS install, without reinstalling Windows. Up to date for playbook 2.3.1; checked on a real PC: install → Undo → every setting compared → install again.

What comes back

  • every registry value, service and scheduled task Domain OS changed (also the ones only SYSTEM or Windows itself may change);
  • power plan, hibernation, UAC prompt, theme, mouse, taskbar and Start pins, wallpapers, right-click menu, OneDrive;
  • the Toolbox device layout (after the restart).

What stays

  • your files, games, programs and saves — Undo changes settings only;
  • removed apps (Teams, Copilot …): Undo lists them, install the ones you want from the Microsoft Store;
  • Visual C++ / DirectX runtimes, the Domain OS pictures folder, Toolbox itself (Undo from Start does not uninstall it).

How to undo

  1. Optional but wise: Start → Create a restore point → Create.
  2. Close games and anti-cheats.
  3. Start → Domain OS → Undo Domain OS → allow the administrator prompt.
  4. Wait for the end (1–5 min) and do not close the window. The last lines should say Failed: 0 and Restart the computer to finish.
  5. Restart.

Check that everything is back

  • Start → Domain OS → Check Domain OS: it should say Domain OS was undone and Windows health all PASS.
  • A full comparison of every saved setting: Verify-Undo.ps1, PowerShell as administrator: 
    powershell -ExecutionPolicy Bypass -NoExit -File "C:\Path\Verify-Undo.ps1"
    Result: Result: … back as before, … different.
  • Normal differences (Windows changes them itself): GameDVR_Enabled, ContentDeliveryManager values, a Windows Spotlight wallpaper coming back as a still picture.

If something says FAILED

Nothing is lost: the saved state is kept when anything fails. Restart and run Undo Domain OS again.

Still FAILED? Post in Discord, channel 14・help: C:\ProgramData\Domain OS\Logs\undo.log and the Check Domain OS report from the desktop.

Do not delete C:\ProgramData\Domain OS — the saved original state lives there.

After Undo and a restart, any Domain OS version installs like the first time.
