▍Undo

How to undo Domain OS

Undo puts Windows back to how it was before your very first Domain OS install, without reinstalling. For playbook 2.3.4; checked on a real PC with the full cycle: install, undo, every setting compared, install again.

Time: 1–5 minutes and a restart/Your files are not touched/Can be repeated

01▍What comes back

What Undo puts back and what it keeps

Undo changes only the settings Domain OS changed.

▍Comes back
  • Every registry value, service and scheduled task Domain OS changed, also the ones only SYSTEM or Windows itself may change
  • Power plan, hibernation, the UAC prompt, theme, mouse
  • Taskbar and Start pins, wallpapers, the right-click menu, OneDrive
  • The Toolbox device layout (after a restart)
▍Stays
  • Your files, games, programs and saves: Undo changes only settings
  • Removed apps (Teams, Copilot…): Undo shows their list, the ones you need come from the Microsoft Store
  • Visual C++ and DirectX libraries, the Domain OS pictures folder, Toolbox itself (Undo from Start does not remove it)
02▍Before

Getting ready

Half a minute, and Undo goes smoothly.

  1. Optional but wise: Start → Create a restore point → Create.
  2. Close games and anti-cheats (FACEIT, Vanguard and others).
03▍Undo

Run Undo

One program from Start; it does the rest by itself.

  1. Start → Domain OS → Undo Domain OS → allow the administrator prompt.
  2. Wait until it ends (1–5 minutes), do not close the window. The last lines must say Failed: 0 and Restart the computer to finish.
  3. Restart the PC.
▍Do not delete this folder

C:\ProgramData\Domain OS: the saved original state is there, Undo works from it.

04▍Check

Check that everything is back

Two checks: a quick one and a full one.

  1. Start → Domain OS → Check Domain OS: it must say Domain OS was undone, and the Windows health section is all PASS.
  2. Full comparison of every saved setting: Verify-Undo.ps1, PowerShell as administrator:
    powershell -ExecutionPolicy Bypass -NoExit -File "C:\Path\Verify-Undo.ps1"
    Result: Result: … back as before, … different.
▍Normal differences

Windows changes these by itself: GameDVR_Enabled, ContentDeliveryManager values, Windows Spotlight wallpapers that come back as a plain picture.

05▍If FAILED

If something went wrong

Nothing is lost: on any error the saved state stays.

  1. Restart and run Undo Domain OS again.
  2. FAILED again? Write in Discord, channel ❓・help: attach C:\ProgramData\Domain OS\Logs\undo.log and the Check Domain OS report from the desktop.
▍Install again

After Undo and a restart any Domain OS version installs as if for the first time.
