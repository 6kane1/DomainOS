Версии и изменения

Ссылки на файлы есть только у текущей версии: ставьте всегда её. Старые версии здесь — для истории.

Domain OS 2.3.1 · Toolbox 1.16.1 22.11.2026текущая

  • Изменения Windows те же, что в 2.3.0; в плейбуке новый Toolbox 1.16.1.
  • Toolbox 1.16.1: датчик ожиданий: Dynamic Top-5 выбирает потоки игры по загрузке и по тому, как долго они ждут ядро, и переставляет поток только по понятной причине.
  • Toolbox 1.16.1: на процессорах с одним кэшем и без E-ядер (7800X3D, 9800X3D, 7700X) игре все ядра; кнопка «Маска ядер» с короткой инструкцией.
  • Toolbox 1.16.1: ядра драйвера видеокарты и прерываний держатся 60 с, потоки игры больше не переставляются каждые несколько секунд; чёрный ящик объясняет каждый рывок простыми словами.

Domain OS 2.3.0 · Toolbox 1.16.0 21.11.2026

  • Остаются «Советы», Cortana, Карты, «Мобильные устройства»; Store остаётся даже с Maximum. Перед установкой AME просит выключить переключатели «Безопасности Windows»: после перезагрузки включите их обратно.
  • Больше рекламы и подсказок выключено, уровень диагностических данных 0, брандмауэр включён без уведомлений, запрещены сборки Insider; HAGS всегда включён; без галочки UAC спрашивает пароль или PIN.
  • Toolbox 1.16.0: страница «Обновления и тесты», только Dynamic Top-5, «Применить раскладку» с подтверждением, защита от фоновых всплесков; на 6 ядрах и меньше все ядра игре.

Domain OS 2.2.4 · Toolbox 1.15.0 19.11.2026

  • Откат проверен полным циклом на реальном ПК: установка → Check → откат (Failed: 0) → сверка каждой настройки → снова установка.
  • Откат возвращает службы и задания, которые может менять только SYSTEM, и значения, которые может менять только Windows (TrustedInstaller).
  • Откат снова возвращает порядок значков на панели задач; установка больше не останавливается на обоях.
  • Архив плейбука собирается и аттестуется на GitHub.

Domain OS 2.2.0 · Toolbox 1.15.0 19.11.2026

  • Установка останавливается при любой ошибке и в конце проверяет всё, что поставила.
  • Новое: «Пуск» → Domain OS → Check Domain OS — состояние ПК и готовность отката, ничего не меняет.
  • Запрос UAC по умолчанию остаётся; откат возвращает больше (службы SYSTEM, план питания, значки, обои).
  • Toolbox 1.15.0: подписанные обновления, разгон AMD Radeon (за флагом), уведомление о новом плейбуке, данные в защищённой папке.

Domain OS 2.1.1 · Toolbox 1.14.1 18.11.2026

  • Только Windows 11 Pro, 25H2 и 26H2; на других редакциях установка останавливается до любых изменений.
  • Удалённые приложения не возвращаются после обновлений; полное контекстное меню сразу; «Завершить задачу» на панели задач.
  • Discord и голосовые чаты больше не приглушают звук игры; коды ошибок на синем экране.
  • Новые обои 4K и тема Domain OS; уведомления работают по умолчанию; Spotify больше не удаляется.

Domain OS 2.0.0 · Toolbox 1.11.1 18.11.2026

  • Игра не попадает на ядра драйвера видеокарты: Toolbox находит их с 3-й секунды игры.
  • Auto больше не выключается, когда закрываешь игру.
  • Убрано то, что в замерах не помогло: парковка ядер, жёсткая привязка потоков, сторож времени кадра и другое.
  • Только русский и английский язык, полный перевод.
