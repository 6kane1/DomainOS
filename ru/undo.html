Как откатить Domain OS

Откат возвращает Windows к состоянию до вашей самой первой установки Domain OS — без переустановки Windows. Актуально для плейбука 2.3.0; проверено на реальном ПК: установка → откат → сверка каждой настройки → снова установка.

Что возвращается

  • каждое значение реестра, служба и задание, которые менял Domain OS (в том числе те, что может менять только SYSTEM или сама Windows);
  • план питания, гибернация, запрос UAC, тема, мышь, значки на панели задач и в «Пуске», обои, меню правой кнопки, OneDrive;
  • раскладка устройств Toolbox (после перезагрузки).

Что остаётся

  • ваши файлы, игры, программы и сохранения — откат меняет только настройки;
  • удалённые приложения (Teams, Copilot …): откат показывает их список, нужные ставятся из Microsoft Store;
  • библиотеки Visual C++ / DirectX, папка с картинками Domain OS, сам Toolbox (откат из «Пуска» его не удаляет).

Как откатить

  1. Не обязательно, но разумно: «Пуск» → Создание точки восстановления → Создать.
  2. Закройте игры и античиты.
  3. «Пуск» → Domain OS → Undo Domain OS → разрешите запрос администратора.
  4. Дождитесь конца (1–5 мин), окно не закрывайте. В последних строках должно быть Failed: 0 и Restart the computer to finish.
  5. Перезагрузите ПК.

Как проверить, что всё вернулось

  • «Пуск» → Domain OS → Check Domain OS: должно быть Domain OS was undone, а раздел Windows health — весь PASS.
  • Полная сверка каждой сохранённой настройки: Verify-Undo.ps1, PowerShell от администратора: 
    powershell -ExecutionPolicy Bypass -NoExit -File "C:\Путь\Verify-Undo.ps1"
    Результат: Result: … back as before, … different.
  • Нормальные отличия (Windows меняет их сама): GameDVR_Enabled, значения ContentDeliveryManager, обои «Windows: интересное», вернувшиеся обычной картинкой.

Если где-то FAILED

Ничего не потеряно: при любой ошибке сохранённое состояние остаётся. Перезагрузитесь и запустите Undo Domain OS ещё раз.

Снова FAILED? Напишите в Discord, канал 14・help: файл C:\ProgramData\Domain OS\Logs\undo.log и отчёт Check Domain OS с рабочего стола.

Не удаляйте C:\ProgramData\Domain OS — там лежит сохранённое исходное состояние.

После отката и перезагрузки любая версия Domain OS ставится как в первый раз.
