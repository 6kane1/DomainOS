▍Откат

Как откатить Domain OS

Откат возвращает Windows к состоянию до вашей самой первой установки Domain OS, без переустановки. Актуально для плейбука 2.3.1; проверено на реальном ПК полным циклом: установка, откат, сверка каждой настройки, снова установка.

Время: 1–5 минут и перезагрузка/Ваши файлы не трогаются/Можно повторять

01▍Что вернётся

Что откат возвращает и что оставляет

Откат меняет только настройки, которые менял Domain OS.

▍Возвращается
  • Каждое значение реестра, служба и задание, которые менял Domain OS, в том числе те, что может менять только SYSTEM или сама Windows
  • План питания, гибернация, запрос UAC, тема, мышь
  • Значки на панели задач и в «Пуске», обои, меню правой кнопки, OneDrive
  • Раскладка устройств Toolbox (после перезагрузки)
▍Остаётся
  • Ваши файлы, игры, программы и сохранения: откат меняет только настройки
  • Удалённые приложения (Teams, Copilot…): откат показывает их список, нужные ставятся из Microsoft Store
  • Библиотеки Visual C++ и DirectX, папка с картинками Domain OS, сам Toolbox (откат из «Пуска» его не удаляет)
02▍Перед откатом

Подготовка

Полминуты, и откат пройдёт спокойно.

  1. Не обязательно, но разумно: «Пуск» → Создание точки восстановления → Создать.
  2. Закройте игры и античиты (FACEIT, Vanguard и другие).
03▍Откат

Запустите откат

Одна программа из «Пуска», всё остальное она делает сама.

  1. «Пуск» → Domain OS → Undo Domain OS → разрешите запрос администратора.
  2. Дождитесь конца (1–5 минут), окно не закрывайте. В последних строках должно быть Failed: 0 и Restart the computer to finish.
  3. Перезагрузите ПК.
▍Не удаляйте эту папку

C:\ProgramData\Domain OS: там лежит сохранённое исходное состояние, по нему откат и работает.

04▍Проверка

Проверьте, что всё вернулось

Две проверки: быстрая и полная.

  1. «Пуск» → Domain OS → Check Domain OS: должно быть Domain OS was undone, а раздел Windows health весь PASS.
  2. Полная сверка каждой сохранённой настройки: Verify-Undo.ps1, PowerShell от администратора:
    powershell -ExecutionPolicy Bypass -NoExit -File "C:\Путь\Verify-Undo.ps1"
    Результат: Result: … back as before, … different.
▍Нормальные отличия

Windows меняет их сама: GameDVR_Enabled, значения ContentDeliveryManager, обои «Windows: интересное», вернувшиеся обычной картинкой.

05▍Если FAILED

Если что-то пошло не так

Ничего не потеряно: при любой ошибке сохранённое состояние остаётся.

  1. Перезагрузитесь и запустите Undo Domain OS ещё раз.
  2. Снова FAILED? Напишите в Discord, канал 14・help: приложите файл C:\ProgramData\Domain OS\Logs\undo.log и отчёт Check Domain OS с рабочего стола.
▍Поставить снова

После отката и перезагрузки любая версия Domain OS ставится как в первый раз.
