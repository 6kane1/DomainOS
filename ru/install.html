Установка Domain OS с нуля

От загрузки официального образа Windows 11 Pro до первой игры. Делайте шаги по порядку и ничего не пропускайте: почти все проблемы после установки — это пропущенный шаг, изменённый образ Windows или сторонние «оптимизаторы».

Время: около часа, из него сам плейбук — минут 10/Нужна флешка от 8 ГБ/Windows 11 Pro · 25H2 / 26H2

01▍Подготовка

Что подготовить заранее

Всё это делается на любом компьютере с интернетом, до переустановки.

  1. Сохраните важные файлы на другой диск или в облако. Чистая установка стирает системный диск полностью.
  2. Проверьте, что у вас Windows 11 Pro или есть ключ Pro. Domain OS ставится только на Pro: на Home установка остановится на первом шаге и ничего не изменит. Посмотреть: «Параметры → Система → О системе» (строка «Выпуск»).
  3. Подготовьте папку для флешки (положите её на флешку рядом с установщиком Windows, см. шаг 2):
    • No-WU-Drivers.reg — запрещает Windows ставить свои драйверы;
    • AME Wizard — программа, которая ставит плейбук;
    • Domain-OS-2.3.1.apbx — сам плейбук;
    • драйвер сетевой карты с сайта производителя материнской платы или ноутбука — на случай, если после установки Windows не увидит интернет.
▍Только оригинальный образ

Не используйте «облегчённые», «игровые» и любые изменённые образы Windows и чужие сборки. Плейбук рассчитан на обычную Windows от Microsoft: в изменённых образах уже удалены или сломаны компоненты, и результат непредсказуем.

02▍Флешка

Официальный образ и загрузочная флешка

Windows 11 скачивается только с сайта Microsoft.

  1. Скачайте образ на странице загрузки Windows 11 от Microsoft: раздел «Загрузка образа диска (ISO)», выпуск «Windows 11 (multi-edition ISO)», ваш язык. Один образ содержит и Home, и Pro.
  2. Запишите образ на флешку программой Rufus (или Media Creation Tool от Microsoft). В Rufus после нажатия «Старт» появится окно настроек Windows:
    • можно отметить «Remove requirement for an online Microsoft account» и «Create a local account» — тогда Windows не потребует интернет и учётную запись Microsoft при установке;
    • не отмечайте «Remove requirement for 4GB+ RAM, Secure Boot and TPM 2.0»: TPM и Secure Boot нужны Windows 11 и античитам.
  3. Скопируйте на флешку папку из шага 1 (No-WU-Drivers.reg, AME Wizard, плейбук, сетевой драйвер).
03▍Windows

Чистая установка Windows 11 Pro

Самый важный этап: от него зависит, как будет работать всё остальное.

  1. Отключите интернет: выньте сетевой кабель, Wi-Fi не подключайте. Интернет понадобится только после шага 4.
  2. Загрузитесь с флешки: при включении ПК нажмите клавишу меню загрузки (обычно F8, F11, F12 или Esc — зависит от платы) и выберите флешку. В BIOS ничего отключать не нужно: Secure Boot и TPM оставьте включёнными.
  3. Выберите Windows 11 Pro. На шаге с ключом нажмите «У меня нет ключа продукта» — активировать можно позже. Если установщик не спросил выпуск и ставит Home, значит в BIOS вшит ключ Home: после установки перейдите на Pro своим ключом в «Параметры → Система → Активация → Изменить ключ продукта».
  4. Удалите все разделы на диске, куда ставите Windows, и выберите получившееся «Незанятое пространство». Остальные диски не трогайте. Так не останется старых драйверов, программ и твиков.
  5. Пройдите первую настройку. Если флешка сделана в Rufus с локальной учётной записью, Windows не попросит интернет. В вопросах о конфиденциальности можно выключить всё — плейбук всё равно выключит телеметрию.
04▍Обновления

Первый запуск и обновления

Порядок здесь важен: сначала запрет драйверов, потом интернет.

  1. Запустите No-WU-Drivers.reg с флешки (двойной щелчок → «Да»), пока интернет ещё не подключён. Иначе Windows Update успеет поставить свои, часто старые драйверы.
  2. Подключите интернет. Если интернета нет — поставьте сетевой драйвер с флешки и только его.
  3. Установите все обновления: «Параметры → Центр обновления Windows → Проверить наличие обновлений». Перезагружайтесь и повторяйте, пока не появится «Установлены все последние обновления».
  4. Проверьте версию: Win+R → winver. Должно быть Windows 11 Pro, версия 25H2 (сборка 26200) или 26H2 (сборка 26300). На 24H2 сначала обновитесь через Центр обновления.
▍До плейбука ничего не ставьте

Не ставьте до плейбука драйверы видеокарты, игры, лаунчеры, антивирусы и «оптимизаторы». Исключение — сетевой драйвер, если без него нет интернета. Драйверы поставите после, по подсказке Domain OS.

05▍Плейбук

Установка Domain OS

Около 10 минут. Компьютер в это время не трогайте.

  1. Ноутбук — на зарядку. От батареи AME Wizard не запустится. Интернет должен быть подключён.
  2. Откройте AME Wizard и перетащите в окно Domain-OS-2.3.1.apbx. Если Windows спросит про запуск программы — разрешите.
  3. Отметьте нужные галочки. Если не уверены — оставьте как есть: значения по умолчанию подходят большинству. Что делает каждая галочка, написано в таблице на главной.
  4. Запустите установку и ждите. Не выключайте ПК, не закрывайте окно, не запускайте другие программы. В конце компьютер перезагрузится сам.
▍Если что-то пошло не так

Журнал установки лежит в %ProgramData%\Domain OS\Logs\install.log. Всё можно вернуть: «Пуск» → Domain OS → Undo Domain OS и перезагрузка.

06▍Драйверы

Драйверы после установки

После перезагрузки откроется страница с драйверами именно для вашего ПК.

  1. Драйвер видеокарты — с официального сайта NVIDIA, AMD или Intel (ссылки на странице). Для NVIDIA можно использовать NVCleanstall, чтобы поставить только сам драйвер.
  2. Драйвер чипсета — с сайта AMD или Intel, по ссылке на странице.
  3. Остальное (звук, сеть, Wi-Fi, Bluetooth) — с сайта производителя материнской платы или ноутбука, только если что-то не работает.
  4. Перезагрузитесь.
▍Без сборников драйверов

Не используйте программы-сборники драйверов и «автообновлялки». Они ставят что попало, часто старые или чужие версии. Только официальные сайты.

07▍Toolbox

Первая настройка Toolbox

Toolbox 1.16.1 уже установлен, ярлык на рабочем столе. Это делается один раз.

  1. Откройте Toolbox и нажмите «Включить Auto». Дальше он сам находит игру при каждом запуске.
  2. Когда игра закрыта, один раз нажмите «Оптимизация устройств» и перезагрузите ПК. Если Windows после этого не загрузится, всё откатится само.
  3. По желанию — «Автоподбор» во время игры (около 8 минут), потом «Применить». Подробнее — на странице Toolbox.
08▍Проверка

Проверьте, что всё на месте

Две минуты, и вы уверены, что установка прошла правильно.

01

winver: Windows 11 Pro, 25H2 или 26H2.

02

«Параметры → Игры → Игровой режим»: включён.

03

«Безопасность Windows»: защита от вирусов работает — Domain OS её не трогает.

04

«Пуск» → папка Domain OS: есть Undo Domain OS и Domain OS Toolbox. Значок Toolbox — в трее.

05

Центр обновления Windows работает: обновления безопасности продолжают приходить.

06

В Toolbox на панели «Эта система» видны ваша Windows, видеокарта с драйвером и «Игровой режим: вкл».

09▍Частые ошибки

Из-за чего сборка работает плохо

Каждая из этих ошибок встречалась у пользователей. Проверьте себя.

01

Изменённый или «облегчённый» образ Windows вместо оригинального от Microsoft.

02

Установка поверх старой, давно используемой системы со старыми драйверами и программами. Ставьте на чистую Windows.

03

Сторонние твики, «оптимизаторы» и чистильщики до или после Domain OS. Они меняют систему без описания и без отката; после них помочь уже нельзя.

04

Интернет подключили до No-WU-Drivers.reg — Windows успела поставить свои драйверы. Лечится: поставьте правильные драйверы с официальных сайтов поверх.

05

Не до конца установлены обновления перед плейбуком.

06

Отключённые TPM или Secure Boot — античиты (FACEIT, Vanguard и другие) могут не пустить в игру.

07

Прерванная установка: выключили ПК, закрыли AME Wizard, ноутбук сел. Запустите плейбук ещё раз — он ставится поверх.

08

Сборники драйверов вместо официальных сайтов.
