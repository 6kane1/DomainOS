DPC latency and interrupts: how drivers get in a game's way

What DPCs and ISRs are, why driver work on the game's core causes stutters, how to see it and how Toolbox steers game threads away from those cores without pinning.

When a device (graphics card, network card, USB) reports an event, the processor interrupts its current work and runs a short piece of driver code: the ISR, the interrupt service routine. Longer work is deferred to a DPC, a deferred procedure call that runs on the same core before any normal thread.

While a DPC or ISR runs on a core, a game thread on that core waits, even at the highest priority. Usually that is microseconds. But if a driver works often and for long on the same core as the game's main thread, the delays add up, and the 1% and 0.1% low show them as stutters.

How to see it

  • Toolbox shows which cores the drivers run on, and its thread map shows who gets in the game's way.
  • The Check page report shows the game threads' waits: how often a thread waited for a core and for how long.

Most interrupts and DPCs usually come from the graphics driver and the Windows graphics kernel, almost always on the same cores.

What Toolbox does

Toolbox measures which cores drivers use, live during the game. It gives the game's busiest threads preferred cores without that work. It is a hint to the Windows scheduler (the ideal processor), not hard pinning: threads still move to other cores freely when that is faster. Moves happen only for a clear reason, at most a couple per second. Turning it off puts everything back.

We do not change random registry keys "to reduce latency" and we do not turn off Windows security. If a change does not show in measurements, it is not in Domain OS.

What to measure with

  • Toolbox, the Check page: one button, 30 seconds, a report on the desktop: FPS, 1% and 0.1% low, the longest frame, stutters, the game threads' waits and a hint about what limits the frame rate. Toolbox is free and runs on any Windows 10/11.
  • DomainSchedTest: several runs in a row and one table with means and ranges. The guide is on the Measure page.
